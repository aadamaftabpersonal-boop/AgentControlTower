## External Services / APIs

### 1. Entire CLI (subprocess integration — core of `agent-control-tower`)

- **Where:** `agent-control-tower/backend/app/entire_client.py`
- **How:** Thin subprocess wrapper. `run_json(args)` calls `subprocess.run([settings.entire_bin, *args, "--json"], cwd=settings.repo_root, capture_output=True, text=True, timeout=30)` and JSON-decodes stdout.
- **Functions exposed:** `list_checkpoints()` (→ `entire checkpoint list --json`), `status()` (→ `entire status --json`).
- **Error handling:** raises `EntireCommandError` (custom `RuntimeError` subclass) on non-zero exit, carrying args/returncode/stderr.
- **Config:** `ACT_ENTIRE_BIN` env var selects the binary name/path (default `"entire"` — resolved via PATH); `ACT_REPO_ROOT` selects which repo's checkpoints to read (default: server's cwd).
- **Status in this environment:** **not functional** — no `entire` binary on PATH and no Go toolchain to build one from the repo root's `cmd/entire/` source. `GET /api/checkpoints` returns 500 as a direct consequence (verified by running the server).

### 2. Entire Checkpoint Remote (GitHub-backed)

- Configured in root `.entire/settings.json`: `checkpoint_remote: {provider: "github", repo: "entireio/cli-checkpoints"}`. Checkpoints for this repo's own Entire-tracked sessions push to `entireio/cli-checkpoints` on GitHub via the `git-refs` backend (`checkpoints.primary.type: "git-refs"`).

### 3. Entire Graph (planned, not yet integrated)

- README and hackathon build map (`02_BUILD_MAP.md`) reference an `entire-graph` plugin arriving "from V5 onward" for graph investigation / blast-radius analysis. **Not present in the codebase yet** — this project is at V0.

## Root CLI's Own External Integrations (for context — not part of the hackathon app surface, but what `entire` itself talks to)

The root Go CLI is itself a hub of external integrations (per `CLAUDE.md`), most relevant if `agent-control-tower` grows to depend on more `entire` subcommands:
- **Control plane / entire-api cells** — multi-jurisdiction data plane, resolved via `coreapi` and `auth.CellClientFactory` (JWT-based, per-jurisdiction identity tokens).
- **git remotes** — checkpoint sync elects a single remote (`origin` by default) per repo.
- **Agent integrations** — Claude Code, Gemini CLI, OpenCode, Cursor, Factory AI Droid, Copilot CLI, Pi (hook-based lifecycle integration, not HTTP APIs).
- **OpenAI Privacy Filter (OPF)** — optional external `command` invoked at pre-push for a 9th redaction layer; trust-gated to `.entire/settings.local.json` only.

None of these root-CLI integrations are directly reachable from `agent-control-tower/backend` except via the `entire` subprocess boundary described above — the backend never talks to entire-api or GitHub directly itself.
